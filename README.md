# Advanced Statistical Inference in R

A hands-on project applying classical inferential statistics — confidence intervals
and hypothesis tests for two population means, ANOVA, population proportions, and
population variances — using R and RStudio.

## 📌 What this project covers
- Two-sample t-tests and z-tests (paired & unpaired, equal & unequal variance)
- One-way ANOVA with Levene's test for homogeneity of variance and Fisher's LSD post-hoc test
- One- and two-sample proportion tests
- Confidence intervals and hypothesis tests for one and two population variances (F-test)

## 🛠️ Tools
R, RStudio, packages: `BSDA`, `car`, `agricolae`, `rmarkdown`

## 📁 Structure
​```
report/     -> full R Markdown report (knitted to HTML)
data/       -> data used in the analyses
outputs/    -> saved plots and result tables
​```

## ▶️ How to run
1. Clone this repo: `git clone <your-repo-url>`
2. Open `advanced-statistical-inference-in-R.Rproj` in RStudio
3. Run `install.packages(c("BSDA","car","agricolae","rmarkdown"))`
4. Run each script in `scripts/`, or knit `report/statistical-inference-report.Rmd`
